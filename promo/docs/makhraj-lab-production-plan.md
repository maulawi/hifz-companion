# Makhraj Lab — launch film · production plan

Two masters from one Remotion composition: **1920×1080** (landscape) and
**1080×1920** (vertical), 30 fps. Same timeline, narration and sound; each
format gets its own layout. Forest green dominates (`#092B23 / #0D382E /
#124737`), antique gold `#C8A45D` as accent, ivory `#F4F0E6` for type.
